# ner-chat & blob-boxes

A learning repo with two independent projects, built to get hands-on with document AI tooling in Python:

- **ner-chat**: ask questions about the people, organizations and places in a document. Kreuzberg (text/OCR) →
  GLinker NER layer (GLiNER) → JSON store → single-turn Pydantic AI agent that answers from the store through
  tools, with grounded structured output.
- **blob-boxes**: find each blob in a binary mask and the rotated rectangle with the highest IoU with it.

Design decisions, with the alternatives that were rejected, are in [`DECISIONS.md`](DECISIONS.md).

## Install

Requires [uv](https://docs.astral.sh/uv/) and Python 3.12 or 3.13 (uv installs it if missing).

```bash
uv sync
```

That is the only install command. All dependencies are pinned (`pyproject.toml` + `uv.lock`). torch comes from
the PyTorch CPU index on Linux/Windows, so no CUDA download. Supported: Linux (x86_64/aarch64), Windows x64,
macOS on Apple Silicon. Intel Macs are not supported because torch no longer publishes wheels for them.

## ner-chat

### 1. Extract entities from a document

```bash
uv run ner-chat extract samples/news_article.pdf
```

This writes `entities.json`. The first run downloads the GLiNER model
`knowledgator/gliner-bi-edge-v2.0` (~60M parameters) from Hugging Face. Options:
`--labels person,organization,location,country`, `--threshold 0.5`, `--ner-model <hf id>`, `--store <path>`, `--ocr`.

`samples/news_article.pdf` is a short synthetic news article (fictional people and companies, real places),
generated by `scripts/make_samples.py`. Expected counts (literal occurrences in the document, title included),
and what `extract` finds with the defaults:

| Entity | Label | In the text | Found by `extract` |
|---|---|---|---|
| Lumora Energy | organization | 5 | 5 |
| Valencia | location | 4 | 4 |
| Marta Ibarra | person | 3 | 3 |
| Daniel Okafor | person | 2 | 2 |
| European Investment Bank | organization | 2 | 2 |
| Rotterdam | location | 1 | 1 |
| Spain | country | 1 | 1 |

GLiNER is zero-shot and sensitive to label names: with only `location`, the small model misses "Spain" at every
threshold. Adding `country` to the default labels fixes it without changing anything else (see `DECISIONS.md`).

#### Optional: OCR (`samples/news_article.png`)

Kreuzberg bundles the Tesseract engine but **not its language data**, so OCR does not work after `uv sync` alone.
To enable it, either install Tesseract (`apt install tesseract-ocr`, `brew install tesseract`, or the
[Windows installer](https://github.com/UB-Mannheim/tesseract/wiki)), or download
[`eng.traineddata`](https://github.com/tesseract-ocr/tessdata_fast/raw/main/eng.traineddata) into a folder and
point `TESSDATA_PREFIX` at it:

```bash
TESSDATA_PREFIX=/path/to/tessdata uv run ner-chat extract samples/news_article.png
```

This gives the same counts as the PDF. Without language data, `extract` stops with an explanatory error.

### 2. Ask a question

```bash
uv run ner-chat ask "How many times is Marta Ibarra mentioned?"
uv run ner-chat ask "Is Atlantis mentioned?" --json
```

`ask` reads only `entities.json`, never the original document. The agent reaches the store through tools
(`count_mentions`, `search_entities`, capped `list_entities`, `list_labels`). Every entity in the answer is then
re-checked against the store in code: the name, label and mention count you see always come from the store,
and unknown names show as `not mentioned` with count 0.

**Model** (`--model`, any [Pydantic AI model string](https://ai.pydantic.dev/models/)):

| Option | Needs |
|---|---|
| `ollama:qwen3` (**default**, free, local) | [Ollama](https://ollama.com) running, `ollama pull qwen3`. URL: `--ollama-url`, else `$OLLAMA_BASE_URL`, else `http://localhost:11434/v1`. Use a model with tool calling. |
| `test` | nothing: offline `TestModel`, returns placeholder text (handy to check the plumbing) |
| `anthropic:claude-haiku-5-5`, `openai:...` | `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` (both SDKs are installed) |

If the key is missing or Ollama is unreachable, `ask` prints what to export or start, suggests `--model test`,
and exits with code 2. Each model request is capped at 120 s (`--timeout <seconds>`). The first run after
`ollama pull` can take a minute while the model loads into memory.

## blob-boxes

```bash
uv run blob-boxes samples/masks/example_mask.png -o blob_bounding_boxes.csv
```

The input is a `.npy` array (non-zero = blob) or an image (brighter than mid-grey = blob). The output CSV has one
row per blob:

| Column | Meaning |
|---|---|
| `blob_id` | 1, 2, ... in the order blobs are met reading the mask row by row, top to bottom |
| `center_x`, `center_y` | rectangle centre in pixels; pixel (row r, column c) has its centre at x = c, y = r |
| `width`, `height` | the long side and the short side, in pixels (`width >= height`) |
| `angle` | direction of the long side in degrees, from +x towards +y (clockwise on screen, since y points down), in [-90, 90); squares use [-45, 45) |

Blobs are 8-connected (pixels touching at a corner are one blob). IoU is measured on pixels: the rectangle covers
a pixel when the pixel's centre lies inside it, and the part of a rectangle outside the image does not count.
A summary goes to stderr:

```
8 blobs -> blob_bounding_boxes.csv; IoU mean 0.9735, min 0.8424 (blob 5)
```

The same from Python, on a NumPy array:

```python
from blob_boxes import fit_boxes

for r in fit_boxes(mask):  # mask: 2-D ndarray, non-zero = blob
    print(r.blob_id, r.box.cx, r.box.cy, r.box.width, r.box.height, r.box.angle, r.iou)
```

`samples/masks/example_mask.{png,npy}` (256×256, from `scripts/make_masks.py`) has one shape per hard case:
rotated rectangles, a square at 45°, a rectangle cut by the image border, a 1-pixel-wide diagonal line, a single
pixel, an ellipse and an irregular blob. The rectangles, line and pixel are fitted with IoU 1.

## Tests

```bash
uv run pytest
```

Runs offline, with no API key. The ner-chat test drives the `ask` path with Pydantic AI's `TestModel` against the
fixture store `tests/entities.json`.

## Layout

```
src/ner_chat/      ner-chat: cli, extract (Kreuzberg), ner (GLinker L1), store, agent (tools), grounding, ask
src/blob_boxes/    blob-boxes: cli, io (mask in, CSV out), blobs, box, iou, fit
scripts/           make_samples.py: samples/news_article.{pdf,png}; make_masks.py: samples/masks/example_mask.*
samples/           sample inputs
tests/             unit tests + fixture store
```
